# Driving loop banks

`engine-rpm-0.wav` through `engine-rpm-7.wav` are resampled, level-normalized loop variants of
this repository's existing `engine6.ogg`. `motor-rpm-0.wav` through `motor-rpm-7.wav` are
procedurally synthesized motor tones. All are mono, 44.1 kHz, 16-bit PCM WAV.

The game crossfades adjacent RPM levels as speed/throttle change, using petrol, sport, hybrid
and electric profiles. These are gameplay effects rather than recordings of particular vehicles.
Brake, horn, skid, indicator, crash and mission sounds continue to use the existing OGG effects.
